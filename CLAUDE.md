# Инструкции для ИИ-ассистента

Домашний сервер на Raspberry Pi 4 (Debian 13): Wi-Fi «PiHome» с интернетом от LTE-модема, веб-панель,
камера, датчики, AdGuard, Home Assistant, SMS-оповещения, обход блокировок (zapret). Обзор — `README.md`,
как дорабатывать — **`CONTRIBUTING.md` (прочитать перед работой)**, подробности — README каждой папки.

## Главное

- **Код работает на Pi** (`~/project`), правится здесь. На Pi — `tools/deploy.sh`, команды — `tools/pi.sh`,
  тесты — `tools/test.sh`. Pi: `10.20.0.1` (Wi-Fi) или `10.10.0.1` (кабель), пользователь `dosash`,
  `sudo` без пароля. Пароль SSH даёт пользователь, если вход не по ключу; не записывать его в файлы.
- **Репозиторий публичный.** Секреты (пароли, ключ Zigbee, токен и ID сети ZeroTier, номера телефонов)
  живут только на Pi. Не выводить их значения в чат и логи — только длину или маску.
  Перед каждым пушем — `tools/check-secrets.sh`; найдено что-то — не пушить, разобраться.
- **Коммит и пуш — только когда пользователь попросил.** Автор — Dosash
  `<33052625+Dosash@users.noreply.github.com>`, в конце сообщения — строка `Co-Authored-By:` ассистента.
- **Язык**: интерфейс, README, комментарии, коммиты — по-русски; имена в коде — английские.

## Осторожно

- **Связь с Pi.** SSH обычно идёт через Wi-Fi Pi: изменение точки доступа или NetworkManager обрывает
  сессию. Делать такое скриптом на самой Pi (`sudo systemd-run --unit=… /root/script.sh`) с автооткатом,
  ждать результата циклом `until`, а не `sleep`.
- **Интернет у компьютера**, когда он в PiHome: у PiHome интернет только через модем; если SIM нет —
  связь с ассистентом держится через USB-модем телефона (выше Wi-Fi в порядке служб). Не переключать
  Wi-Fi компьютера и системные настройки самому — попросить пользователя.
- **Выкладка атомарно** (`tools/deploy.sh`), не перезапускать `zapret-panel` во время проверки/подбора,
  не включать службу `nftables`, не делать `pkill -f` по строке из той же SSH-команды.
- **zapret**: включённую стратегию меняет пользователь (или по его просьбе); проверки и подбор
  изолированы от Wi-Fi и не мешают. Стратегии берутся из релиза flowseal, не переписывать их руками.
- **Данные пользователя не удалять** (записи камеры, журналы, настройки): переносить в отдельную папку
  и предлагать удалить самому.
- **Скачивание и установка нового ПО на Pi** — с согласия пользователя: что, откуда, размер; бинарники
  сверять с контрольными суммами релиза.

## Проверка своей работы

- `tools/test.sh` — все тесты; новая логика — с тестами (`unittest`, без сети).
- После выкладки — `systemctl is-active`, журнал службы, сама страница: на десктопе и на ширине
  телефона (390 px), без горизонтальной прокрутки и ошибок в консоли. Скриншоты для README — с
  демонстрационными данными, без личного (номера, пароль Wi-Fi в QR, ID ZeroTier).
- Изменение сети — проверить, что клиенты Wi-Fi переподключились (`iw dev wlan0 station dump`).
